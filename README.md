# DCM APPLE – bản cài

Nơi phát hành bản cài và bản cập nhật của DCM APPLE (tiện ích thanh menu cho macOS). Kho này chỉ chứa file cài, không chứa mã nguồn.

- Tải bản mới nhất: mục **Releases** bên phải (file `.dmg`).
- App đã cài tự kiểm tra bản mới mỗi ngày và chỉ cài bản có đúng chữ ký của DCM Apple.
